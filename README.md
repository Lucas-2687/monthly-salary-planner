# 月薪分配 · 我的月度计划

自托管、单用户的月度预算工具。人民币预算、美元投入与区间收益、人民币储蓄流水，支持跨设备同步、导入导出和冲突检测。

代码可以公开，使用者的财务记录、口令和部署配置保存在自己的运行环境。此仓库不包含个人财务数据，也不提供共享的在线数据库。

## 本地运行

需要 Node.js 24 与 npm。

```sh
npm ci --ignore-scripts
npm run auth:setup
npm run db:migrate
npm run dev
```

在 `http://localhost:3000` 登录。初始化工具生成随机口令，写入本地忽略的 `private/login.txt`，不会打印到终端。保存到密码管理器后删除该文件。生成的 `.env.local` 只用于本地环境，不可上传到 GitHub。

测试使用独立内存数据库和虚构数据，运行 `npm run check` 不需要任何生产密钥。构建仅复制 `public/` 到 `dist/`；Vercel 会单独部署 `api/` 中的 Node.js 服务。

## 部署

见 [部署步骤](docs/DEPLOYMENT.md)。需要自己的 GitHub、Vercel 和 Turso 账户。项目默认禁用 Git 自动部署；普通代码推送不会更新自用站点。稳定版本由部署者显式发布。

## 从现有版本迁移

见 [迁移与核对](docs/MIGRATION.md)。支持旧格式版本 1–9。先在旧站导出，再在新站选择“完整恢复备份”，等待保存完成后导出新副本核对。整个核对完成前保留旧站和原始备份。

## 更新不覆盖个人设置

个人分类、定额、百分比、收入、月份、投入和储蓄都保存在数据库，代码升级不会重设。新建月份可以沿用最近月份的分类；收入重新填写。

每次保存使用数据库原子版本检查，两个设备同时修改时有且只有一个版本成功，另一个提示冲突。最近 30 个保存版本存入同一数据库的历史表；这只用于误操作恢复，不能替代异地备份。

未同步修改会以当前站点为范围暂存在浏览器，恢复登录后可以找回。仅使用可信设备；退出前要完成同步。退出会清除当前用户的待同步缓存，遇到未保存修改会阻止退出。

## 计算口径

- 所有定额先扣，余额再按百分比分配；百分比合计最多 100%。按分取整时使用最大余数法保持金额合计一致。
- 投入和账户总值统一为 USD，同一天允许多笔，按日期和录入顺序计算。
- 区间收益率 =（本次入金前总值 − 上次入金后总值）÷ 上次入金后总值；复利收益为各区间 `(1 + r)` 连乘减 1。
- 手动估值可计入最近入金后的区间；跨年区间整体归入结束年份，并非严格自然年度收益。
- 储蓄余额 = 期初余额 + 存入 − 取出；预算储蓄与实际流水各自独立。

## 安全边界

应用是部署者自用的单用户空间，不开放注册。口令使用 scrypt 哈希，登录使用 HttpOnly、SameSite=Strict Cookie，HTTPS 部署使用 Secure 与 `__Host-` 前缀。所有数据接口验证登录，写操作验证固定站点来源，私有响应禁止缓存。限流计数保存在数据库；原始 IP 不入库。

Turso 凭据只存在服务端。持有生产环境或 Turso 管理权限的人仍可能访问数据；本项目不提供端到端加密。数据迁移到第三方托管前，应选择自己信任的账户和权限。

数据请求上限 3 MB，低于 Vercel Functions 的请求体上限。暂不提供多人账号、共享权限或离线完整编辑模式。
